# Grocerly — Smart Grocery Management System
Final-year CSE project MVP.

## Run
Open `index.html` in a modern browser. No server or build step is required.

## Included modules
- Dashboard / KPI overview
- Inventory CRUD
- Search, category and stock-status filtering
- Low-stock and expiry monitoring
- Shopping list with quantity controls and completion state
- Budget and trip cost estimation
- Analytics with category-value visualization and smart insights
- Dark/light mode
- LocalStorage persistence
- JSON report export
- Responsive mobile layout

## Tech
HTML5, CSS3, Vanilla JavaScript, LocalStorage.
